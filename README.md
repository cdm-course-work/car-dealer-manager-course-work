# Car Dealer Manager

Car Dealer Manager is a simple software system designed to help small car dealerships manage their vehicle inventory, expenses, and sales process.

## Who is it for?

The system is intended for car dealership employees and owners who need a simple way to keep track of vehicles from the moment they are added to the inventory until they are sold.

## What problem does it solve?

Small dealerships often track vehicles, expenses, prices, and sales using spreadsheets, notes, or separate tools. This can make it difficult to keep information organized and up to date.

Car Dealer Manager provides a single place where dealership staff can:

- Add vehicles
- View all vehicles
- View detailed vehicle information
- Edit vehicle information
- Add and review vehicle expenses
- Set a sale price
- Mark vehicles as sold
- Track vehicle status and availability

## Main Features

### Vehicle Management
- Add new vehicles
- View vehicle list
- View vehicle details
- Edit vehicle information

### Sales and Finance
- Add vehicle expenses
- View vehicle expenses
- Set sale price
- Mark vehicles as sold

## Development Process

The project is organized using Scrum with two sprints.

Work is tracked in Jira using:
- Epics
- Stories
- Tasks
- Bugs
- Subtasks

Each development item is connected to GitHub through:
- Jira work item key
- Git branch
- Commits
- Pull Request
- Merge into `main`

## Repository Workflow

Example:

`CDM-4 View vehicle list`

Branch:

`CDM-4-view-vehicle-list`

Commit:

`CDM-4 Add vehicle list specification`

Pull Request:

`CDM-4 View vehicle list`

After the Pull Request is merged, the Jira work item is moved to Done.
